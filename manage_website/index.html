Blogging Walkthrough

1. Start the manager

Windows: double-click `start_manager.bat`. Mac: double-click `start_manager_mac.command`. If the script says Python is missing, install Python 3.

2. Use the right browser

Use Chrome or Edge. Safari and Firefox usually cannot give this page permission to edit local files.

3. Choose the repo folder

Click `Choose Site Folder` and select the `hotsoursoup.github.io` folder. The manager will load `site.config.json`, `himanshu.json`, and `aryan.json`.

4. Create posts

Use `Create Post`, choose the author, add title/date/tags/theme, then build the post with scrapbook blocks. Press `+` to add a block, use `Up`/`Down` to move it, and `X` to remove it.

5. Confirm identity before writes

Saving, deleting, or resequencing an author's posts asks you to type that author's display name exactly, such as `Aryan` or `Himanshu`.

6. Publish

After saving locally, review the public pages, then commit and push from Git. This manager does not publish by itself.

Creative bits

Draft posts stay hidden from the public site. The post board can reorder posts. The theme lab edits reusable post themes. The preview panel gives a quick read before you save.
